# Translation Universal

Automatic Indonesian localization support for Minecraft Java 1.21.1 on NeoForge 21.1.251+.

**Author:** ikyy

## Current target mods
- Tensura (2.0.1.5)
- Tensura Reincarnated Nightmares (1.0.6.5)
- Nightmare Utils (0.1.0)

## Build
Requires Java 21 and Gradle 8.10.2 or newer.

```bash
gradle build
```

GitHub Actions builds the mod on every push and on manual dispatch. The JAR is uploaded as a workflow artifact.

## Status
Initial NeoForge project scaffold committed. Translation resources and in-game compatibility are still being implemented and validated; this is not a finished release yet.
